# Cập nhật tiến độ theo tuần

Dùng lịch trong `../agile-plan.md`; một sprint có thể gồm nhiều tuần. Mỗi báo cáo ghi ngày cập nhật thực tế, người phụ trách và liên kết commit/PR. Báo cáo SP1 hiện tại ở `SP1.md` là tổng hợp tại thời điểm đưa code lên GitHub.

Mẫu để tạo `SP2-W04.md`, `SP2-W05.md`… vào tuần thực sự làm:

```markdown
# SP__ — Tuần __ (__/__/2026–__/__/2026)

Ngày cập nhật thực tế: ...
Mục tiêu tuần: ...

| Người phụ trách | Công việc | Kết quả thực tế | Commit/PR |
|---|---|---|---|
| Phạm Minh Hùng | ... | Đạt / chưa xong / bị chặn | ... |
| Nguyễn Hoàng Phú | ... | ... | ... |
| Phạm Minh Hoàng | ... | ... | ... |

Kiểm chứng: lệnh, ngày chạy, kết quả và phần chưa kiểm chứng.
Vấn đề còn lại: ...
Kế hoạch tuần tiếp: ...
Review/retrospective: Continue / Stop / Try.
```

Không điền test pass, tên người đã review hoặc commit nếu chưa có bằng chứng. Nếu chỉ hoàn thiện tài liệu, ghi rõ không có chức năng mới.
